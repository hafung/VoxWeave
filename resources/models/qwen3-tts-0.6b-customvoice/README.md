# Qwen3-TTS 0.6B CustomVoice resources

This is VoxWeave's default text-only narration model because it provides the bundled Vivian, Serena, and Ryan preset voices.
Run `powershell -ExecutionPolicy Bypass -File scripts/download-model.ps1 -Variant custom-0.6b` on an online build machine. Binary weights stay outside Git and are copied as external files into the directory-portable package.
